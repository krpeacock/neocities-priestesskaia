About

Priestess Kaia is a dyke and organizer in the SF Leather community — co-organizer of Puddle, a sapphic play party, and the T4T Leather Community.

This site is deliberately small: handwritten HTML and CSS, a few of my own web components, no frameworks, no trackers. The event tiles on these pages are fetched live from my own Gathio instance — the source of truth for dates, venues and RSVPs.

The ecosystem

This corner of the web is built on community-owned tools:

  • Neocities hosts this site — a non-profit hosting platform for handwritten, personal web pages.
  • Gathio runs the event platform behind the listings here — free, open source, self-hostable, and federated.
  • ActivityPub is the open protocol those events speak, so they work with Mastodon and the wider fediverse instead of a walled garden.
  • Custom elements — <gathio-events> and <site-footer> — are plain browser-native web components, defined in /components/.
